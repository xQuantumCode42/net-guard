# NetGuard 1.1.0 Linux implementation plan

**Goal** — Run NetGuard on Ubuntu and Arch Linux with a desktop GUI and a CLI.

**Architecture** — Both entry points use the same systemd service and its owner-restricted Unix socket. The service owns the policy database. nftables remains the native blocking backend.

- Build and exercise CLI status, enable, pause, observe, import and export.
- Use the same service policy from the Linux desktop. Start the installed service through the system authorization prompt.
- Build x64 artifacts into the versioned release directory. Record the distribution used to produce each binary.
- Verify system startup, state sharing and IP blocking in an isolated Linux environment. Record which desktop and distribution tests actually ran.
